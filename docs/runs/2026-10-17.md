## 3. Design system foundations

- Tokens: base layer (`--brand-*`) converted to oklch, hex kept beside each; the system layer renamed to purpose
  names (`--surface-paper`, `--surface-raised`, `--ink-muted`, `--line-hairline`, `--action`…) across every file;
  Light and Lantern only swap that layer. Purpose colours exposed to Tailwind through `@theme` (`bg-surface-paper`…).
  One unused base colour (kiri) and one unused token (`--letter-blur`) deleted.
- Motion: 18 duration/easing tokens down to 3 durations (150 / 300 / 600 ms), 2 easings and 1 spring. Loops are
  multiples of slow. All three durations are 0 under reduced motion.
- Surfaces: `--elevation-paper / raised / sheet / overlay`. Grain stays on every paper surface. Blur: the scene's
  edge backdrop blur and the sheet overlay blur removed, and the names no longer animate a blur. The nav keeps the
  only backdrop blur (laptop bar; phones get theirs in section 4).
- Type: Display and Heading are fluid clamps (56 to 88, 28 to 32). Body, Small and Label stay fixed so inputs
  stay 16px (iOS zoom).
- Button: primary / secondary / quiet / link, sm / md / lg (+ icon), loading state with aria-busy and a spinner,
  spring press to 0.97. outline → secondary, ghost → quiet, lg → md (same height as before). The fortune's
  "Save to my phone" is the link variant in the slip's own ink.
- Chips: one `chip-shape` (32 tall, 44 tap area, control radius, hairline, 12 padding) for the date chip, status
  chips, the Replied badge, reply chips and choice chips.
- Primitives in `components/ui`: one Sheet (the reply, the journey map and the driver card now all use it, so the
  driver card gets Radix's focus trap and Esc instead of its own), Accordion with `Disclosure` (merged in),
  Field (form-field + FieldError merged), CheckboxGroup + Chip (new, for dietary in section 8), Toast (moved).
  Deleted: ui/label (unused), disclosure.tsx, form-field.tsx.
- Modern CSS: The day's timeline draws with a CSS scroll timeline instead of a scroll listener (complete and still
  where unsupported); view transitions between pages on laptops; toasts use `@starting-style`;
  `interpolate-size: allow-keywords`; the laptop sheet height uses dvh. `field-sizing` was already in use.
- Listeners: story track (scroll → IntersectionObserver), arrival note (resize → ResizeObserver), nav marker (window
  resize dropped, ResizeObserver already there), timeline (shared scroll listener deleted with `lib/scroll.ts`).
  Every requestAnimationFrame now goes through one loop, `src/lib/frame.ts` (with a test).
- Counts: components 42 → 41; scroll/resize listeners plus direct rAF calls 19 → 2 (the keyboard's VisualViewport
  resize and scroll, which have no observer equivalent).
- Decision: "Base UI primitives" read as a base set of primitives on the Radix the site already uses, rather than
  swapping to the Base UI library (a second headless library for the same five parts).
- Skipped: Radix still measures accordion heights (its own animation); swapping to `<details>` with
  `interpolate-size` would change the APG accordion semantics. Popover and container queries had nothing script-driven
  to replace.
- Bundle (gzipped): initial JS 110.0 → 110.2 kB, total JS 181.6 → 180.7 kB, CSS 85.2 → 84.5 kB.
- Caught in checks: Button `asChild` broke Radix Slot (the spinner made two children), fixed; the driver sheet went
