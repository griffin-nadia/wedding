# Griffin & Nadia · wedding site

The invite and RSVP site for Griffin and Nadia's wedding. Each household gets its own link. No logins, no trackers,
no guest data in this repo.

```bash
npm install
npm run dev     # http://localhost:5173/wedding/ with a made-up sample household
npm run build   # dist/, then the leak check
npm test
```

Vite, React and TypeScript, Tailwind, a Google Sheet and Apps Script behind it (`apps-script/`). Art by Nadia; site by
Jehan.
